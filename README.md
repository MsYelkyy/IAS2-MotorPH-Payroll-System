# MotorPH Payroll Management System

MotorPH Payroll Management System is the AOOP version of our payroll system project.

This version improves the old OOP project by using:
- JavaFX for UI
- Maven for build tools
- MySQL for database
- IntelliJ IDEA for development

Current progress:
- domain completed
- application completed
- infrastructure completed
- app/main class exists
- ui still not yet started / still in progress
